# P04: проверка содержания и единый приватный чат

Решение владельца «Единый приватный чат онлайн и очно» реализовано как U-018 / ADR-025. Оно не меняет тексты карточек и само по себе не снимает исходный HOLD содержания.

Продолжайте уже начатую [проверку 139 исправленных карточек](../review470-r3/REVIEW_CHANGED139.md). **Повторно читать 470 карточек из-за единого чата не требуется:** все 2340 языковых полей r3 и r4 совпадают. В форме r3 сохранена историческая фраза о недоступности очного чата; для окончательного r4 она уже не актуальна. Исходную форму и её прошлые сведения не переписывали.

В r4 изменены только применимость/зависимость от канала и последовательные ревизии 143 приватных карточек: online и in_person, обязательный private_text_chat. Новых ID и новых текстов нет. 327 остальных JSON сохранены побайтно. Согласия, ACL, TTL и отзыв доступа действуют в обоих контекстах. [Покарточное обоснование применимости](../review470-r4/applicability143.json).

Точный кандидат для будущего решения:

- Каталог r4: `dfb3a2871d2e988be97cc89cbd50a362eeffa5e60ae0c5258a4219c646f0a270`.
- Pack r4: `sha256:d1a7cb38be173c673665c30ae8e91792940438b675f8830d72503eebed9985d4`.
- [Привязка 139 пунктов формы к точным r4 ID/revision/SHA и неизменному тексту](content-review-binding139.json).
- [Независимая проверка метаданных и истории](../../../reviews/p04/unified-channel-r4-review-round01/REPORT.md): PASS в указанном техническом объёме.
- [Независимая проверка фактического Docker C2](../../../reviews/p04/unified-channel-r4-docker-c2-review-round01/REPORT.md): применимость PASS; это legacy C2, не приёмка смысла и переводов или полный EXIT-P04.

После проверки нужны фактические решения по исправленным карточкам и явное решение о снятии общего HOLD для этого кандидата. Неодобренные карточки остаются неодобренными. Эта страница и технические PASS не создают подпись владельца, профессиональную языковую приёмку или запись о правах. Для local pilot применим ранее разрешённый mock юридических реквизитов; новых юридических документов здесь не запрашивается.

Решение владельца по указанному кандидату: **не получено**.

Проверяющий / дата / замечания: **не заполнено**.

Откат подготовки: оставить r4 неактивным. Исходный r3, авторская история и прежние доказательства сохранены; runtime registry не переключался.
