# Остановка корпуса для изоляции функциональных проверок

Оператор остановил выдачу новых заданий после наблюдаемой конкуренции за ресурсы. Все уже запущенные задания завершились штатно: 62 диапазона exit0, sealed export verified, writer stopped, cleanup COMPLETE. Остальные 2547 диапазонов NOT_RUN. Native case failure не наблюдался. Исходные количества, seed, владельцы диапазонов и принятые результаты сохранены; повторное исполнение принятых диапазонов не разрешается.

Исторический generic BATCH_TERMINAL имеет статус STOPPED_AFTER_FAILURE_NO_RETRY, поскольку общий раннер использует его для любого STOP. Исходный STOP.json отдельно и явно фиксирует OPERATOR_DRAIN_FOR_ISOLATED_FUNCTIONAL_APPLICATION_GATES и not_native_case_failure=true. Оба документа сохранены без изменения. Этот пакет не превращает остановленный корпус в PASS; полный статический C2 и его независимая приёмка вынесены в отдельные пакеты.

Большие исходные sealed файлы остаются локально по RAW-LOCATIONS.json. Здесь сохранены точные host receipts/export pins. Для продолжения требуется отдельная проверяемая привязка только ещё не запускавшихся диапазонов к исходному неизменному плану. Нового sampling или повторов принятых результатов нет.
