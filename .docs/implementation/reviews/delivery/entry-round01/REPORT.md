Earlier reviews correctly observed1.13.10 at their dates but are no longer current. The new release explicitly builds with Go1.27.3 and refreshes its runtime CA image. Its source Dockerfile pins Go1.27.3; actual publisher binary still needs embedded build-info verification. Upstream root LICENSE/NOTICE hashes remain `cfc7749b...` / `6d0f7c5e...`. `go.mod` retains x/net0.59.0 and changes the effective WebRTC fork to4.2.18-warp.7, so do not infer zero advisories or reuse old module bytes. The fixed HTTP/1/WS gateway, loopback SFU listener, disabled TURN/TLS/H2 and no optional outbound integration remain the required configuration boundaries. [Go release history](https://go.dev/doc/devel/release#go1.27.3) and [GO-2026-6809](https://vuln.go.dev/ID/GO-2026-6809.json) confirm the crypto/x509 patch floor. Official publisher artifact is preferable to an unnecessary Venus rebuild of1.13.10.

[Debian CVE-2026-107705](https://security-tracker.debian.org/tracker/CVE-2026-107705) still lists bookworm22.12.0-2+deb12u3 and current trixie vulnerable/unfixed. The defect requires attacker-controlled password length greater than127 in AESV3/R6 `revision6Hash`. Direct official upstream22.12 source shows the faulty uncapped length; the CLI programs use33-byte password buffers and Venus passes **no `-opw`/`-upw` flags**, only fixed argv and `/proc/self/fd/N`. The API has no password input, subprocess uses DEVNULL, and encrypted metadata is rejected before rendering. Thus the published long-password prerequisite is excluded by this specific route; a PDF file alone does not supply a CLI password argument. This is a source-based reachability conclusion, not a claim that the package is fixed or arbitrary PDFs are safe. The exact Debian source patchset should be retained with the distribution inventory. The [upstream MR2398 diff](https://gitlab.freedesktop.org/poppler/poppler/-/merge_requests/2398.diff) was successfully fetched directly and hash-bound after the web view was denied; it truncates passwords before hash use and can inform a future explicitly qualified backport if needed.
