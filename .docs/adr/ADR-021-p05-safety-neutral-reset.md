# ADR-021 · Снижение комфорта не возобновляет прежние разрешения

Дата: 2026-10-19. Статус: инженерное исправление в реализации; Docker/review ещё не завершены. Основание: V10 и `P04-GLOBAL-COMFORT` в [полной рецензии владельца](../implementation/evidence/Venus_P04_FULL_REVIEW_450_2026-10-19.md).

## Решение

Во время активной/приостановленной игры обычный редактор настроек остаётся заблокированным: immutable snapshot не переписывается. Всегда доступная остановка остаётся отдельным safety-действием. Дополнительное явное действие «Завершить игру и перейти к нейтральным настройкам» атомарно прекращает текущую сессию и сохраняет собственные comfort0/нейтральные отношения через `me/setup/skip`. Ниже исходный snapshot не редактируется и разрешения из него не возобновляются.

Прежняя реализация очистки настроек только приостанавливала игру. После `resume` будущий раунд мог использовать более высокий comfort из старого snapshot. Теперь текущая игра получает `aborted`, текущие предложения/условия/чат отзываются, resume запрещён. Новый Start требует нового snapshot и preflight с актуальными индивидуальными настройками. Остальные участники не получают изменённое значение, личную причину или автора safety-отказа; общий результат — безопасно завершённая игра.

Действие затрагивает игру только если заявитель входит в её неизменяемый состав. Очистка настроек наблюдателя не прекращает чужую игру. Обычные значения comfort1–4 можно выбрать после завершения игры; снижение не применяется как скрытая правка действующего задания. Рост комфорта не создаёт согласия и действует только в следующей сессии.

## Совместимость, проверка, откат

HTTP request/response shape существующего endpoint сохраняется. Это явное ужесточение его lifecycle-семантики в текущей реализации; исторические P03 архивы/отчёты остаются неизменны. Текущий regression test больше не утверждает, что после сброса настроек разрешён resume: он проверяет abort, запрет resume и неизменность bytes старого snapshot.

Нужны фактические Docker negatives: активный/paused раунд, приватные приглашения и сообщения, повтор/idempotency, наблюдатель, конкурирующий resume/advance, новый snapshot comfort0 и UI без ожидания обычного pending-запроса. Простой unit PASS не закрывает этот список.

При дефекте закрыть новые игровые сессии и оставить самостоятельную остановку. Не возвращать поведение resume с прежним более высоким comfort. Возврат к предыдущему образу требует quiesce активных игр и проверки совместимости; это решение не разрешает откатывать отзыв согласия или индивидуальные настройки.
