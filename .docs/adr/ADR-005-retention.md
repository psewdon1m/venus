# ADR-005 · Retention отношений, primary и backup

**Дата:** 2026-10-18 · **ревизия:** P00-2 · **статус:** `ACCEPTED`.

**Ответственный профиль:** Product / Privacy / Operations. **Принимающий:** Владелец проекта + Privacy/Operator. **Последний рубеж:** EXIT-P05.

## Контекст и вопрос

Room-only preferences; idle expiry24h, access revoke при close, primary delete<=24h; backup максимум7d предлагается отдельно от исходного baseline.

## Варианты / подготовленное решение

Рекомендация room-only без cross-room профилей; альтернативные конечные сроки требуют явного решения.

## Доказательства для принятия

U-002; deletion/expiry/restore с синтетическими часами; separate encrypted key recovery.

## Последствия, совместимость и откат

Не продлевать срок скрыто; при restore повторить tombstones/revocations до доступа. Удалённое не восстанавливать для отмены решения.

## Принятое решение P00-2 · 2026-10-18

Room-only. Idle expiry24h; primary deletion<=24h after close; encrypted backups<=7days. При восстановлении применяются deletion/expiry/revocation до открытия доступа. Продление сроков требует нового решения.
