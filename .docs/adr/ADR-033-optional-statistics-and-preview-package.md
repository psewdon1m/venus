# ADR-033 — необязательная статистика P03 и предварительный GHCR-образ

Статус: ACCEPTED_BY_OWNER_U021. Scope: standalone local pilot, P06. Решение владельца от 2026-10-25 Europe/Istanbul имеет приоритет над прежним требованием запускать четыре статистические проверки при каждом CI.

Четыре существующих измерения `invariants`, `fairness`, `gf`, `inference` переносятся без изменения алгоритмов, выборок и порогов из автоматического Venus CI в отдельный `Venus optional P03 statistics`, запускаемый вручную через `workflow_dispatch`. Они не являются обязательными status checks для main. Отмена незавершённого прогона сохраняется как CANCELLED, а не PASS. Исторические P03/P04/P05 snapshots и их гейты остаются доказательствами прежних ревизий; их инструменты и отчёты не переписываются.

Для новых изменений обязательны пять автоматических проверок: `quality`, `container-smoke`, `p02-integration`, `p03-integration`, `p06-release-integration`. Strict checks, PR process, запрет force push, linear history и остальные настройки защиты main сохраняются. Новая политика действует после фактической проверки настроек GitHub.

Владелец отдельно поручил немедленно опубликовать текущий package, чтобы затем самостоятельно сделать его Public. `Venus preview image` публикует образ с точным Git SHA в теге `p06-preview-<sha>` и version `0.0.0`. Это предварительный unsigned OCI image, без service signing key, GitHub Release и утверждения EXIT-P06. Первый bootstrap запускается push изменения этого workflow в текущую P06-ветку; далее доступен ручной запуск. Публикация qualified `venus-v0.0.1` сохраняет отдельные подпись, гейты, точный main/tag и проверку анонимного доступа после изменения видимости владельцем.

Проверка: статический разбор workflow/permissions; обязательный CI текущего head; независимые Engineering и Security reviews; фактический OCI digest публикации и subsequent anonymous pull. Четыре статистических измерения для проверки этого изменения не запускаются.

Откат: новой ревизией вернуть автоматическую матрицу и четыре required contexts по решению владельца; не менять ранее опубликованный SHA-tag/digest и не выдавать предварительный образ за подписанный выпуск. P07 не разрешён.
