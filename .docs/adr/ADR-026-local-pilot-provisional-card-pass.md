# ADR-026 · Временное принятие карточек для локального пилота

Дата: 2026-10-20. Статус: `OWNER_PROVISIONAL_PASS / TECHNICAL_GATES_REQUIRED`.

Прямая команда владельца: «Карточки пока считаем pass. Добивай гейты этапа 5». [U-019](../implementation/user-decisions.v4.json) принимает текущий набор470 r4 для standalone local friends pilot. Точные catalog SHA256 `dfb3a2871d2e988be97cc89cbd50a362eeffa5e60ae0c5258a4219c646f0a270`, pack `sha256:d1a7cb38be173c673665c30ae8e91792940438b675f8830d72503eebed9985d4`.

Ожидание139 ответов и исходный owner450 HOLD больше не блокируют человеческое принятие содержания этого набора в данном scope. Старые документы, незаполненные поля и исходные статусы сохраняются: решение не приписывает владельцу проведённую построчную RU/EN/TR проверку. Это временное продуктовое принятие, а не юридическое заключение или разрешение публичного production launch.

Технические требования не отменяются: реальное покрытие, семантическая карта, безопасность, согласия, runtime, интерфейс, статистические гейты и независимая приёмка остаются обязательными. Подмена synthetic draft нормальным runtime bundle без проверки его точных привязок запрещена. Активация требует отдельной прослеживаемой ревизии release registry после технической готовности; исходные draft snapshots не редактируются.

При отзыве решения запретить новые starts и отозвать точный pack штатным механизмом. История, исключения, прошлые отзывы и доказательства сохраняются. Согласия пользователей и удалённые данные не восстанавливаются.
