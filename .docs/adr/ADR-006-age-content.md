# ADR-006 · Возрастная и контентная политика

**Дата:** 2026-10-18 · **ревизия:** P00-2 · **статус:** `ACCEPTED`.

**Ответственный профиль:** Product / Safety. **Принимающий:** Владелец проекта + независимый safety reviewer. **Последний рубеж:** EXIT-P04.

## Контекст и вопрос

Определить аудиторию, eligibility и границы романтических/physical карточек до review/publish.

## Варианты / подготовленное решение

Рекомендация initial18+ без сексуальных/опасных/принуждающих заданий; альтернатива только neutral/friendship каталог. Механизм age eligibility ещё не утверждён.

## Доказательства для принятия

U-003, policy, независимый safety/tri-locale review; machine validator не доказывает возраст/безопасность текста.

## Последствия, совместимость и откат

Карантин sensitive cards; не менять reviewed status задним числом; остановить затронутые активные задания.

## Принятое решение P00-2 · 2026-10-18

При открытии сервиса — явное принятие действующей версии оферты и подтверждение18+. Это пользовательская декларация, не документальная верификация. Непринятие блокирует вход/создание/join. Safety exits остаются доступны при смене версии политики; контентные запреты исходной спецификации сохраняются.

Основание: U-003 — [прямое решение владельца](../implementation/user-decisions.v1.json). Предыдущие варианты выше сохраняются как история; текущим является этот раздел. Принятие продукта/процесса не утверждает реализованность и не закрывает технический гейт без evidence.
