# ADR-001 · Размещение и сеть внешнего LiveKit

**Дата:** 2026-10-18 · **ревизия:** P00-1 · **статус:** `DEFERRED`.

**Ответственный профиль:** RTC / Infrastructure. **Принимающий:** Оператор и RTC reviewer. **Последний рубеж:** EXIT-P09.

## Контекст и вопрос

Выбрать измеренный VPS/network профиль; 1 publisher + 7 viewers, ICE/UDP, CPU/egress; LiveKit обслуживается независимо.

## Варианты / подготовленное решение

Самостоятельно provisioned LiveKit на подтверждённом host; альтернативный host/сетевой профиль после сравнения измерений.

## Доказательства для принятия

Benchmark, external ICE/UDP, token/revoke tests, реальные latency percentiles.

## Последствия, совместимость и откат

Вернуть совместимую SFU версию собственным runbook; отключить grants Cinema до восстановления.
