# ADR-035 — Функциональные этапы перед общей приёмкой P07

Статус: OWNER_DECIDED_EXECUTION_ORDER. Основание: прямые сообщения владельца от2026-10-25 и команда «Начинай работу». U-022/U-023, user-decisions.v7.json. Предыдущий планv2 сохранён byte-for-byte в pipeline-v3-owner-order01.

P08–P11 и адаптация preza предшествуют финальному P07. Stage entry не объявляет отсутствующий P07 принятым; readiness общего стенда ещё требуется. Все изменения этапа до тестов; затем только impacted checks, без длинной статистики, исправления и независимые exit gates до PASS. Недостающие реальные контент/устройства/инфраструктурные входы сохраняют свой HOLD. Другие этапы могут продолжаться независимо; код не означает принятие неподтверждённой платформы.

Совместимость: исторические snapshots, contracts, traceability и accepted proofs не переписываются; новый код/контракт имеет новый source identity. Не менять immutable venus-v0.0.1. Новые media tables additive, feature defaults unavailable без настроенного источника. Адаптация preza использует Rooms authority вместо независимых публичных паролей/slugs/admin key. P07 повторно проверяет все включённые функции вместе.

Откат: выключить admission затронутой функции, прекратить её активные grants/streams, сохранить данные/protected ledgers и вернуться к совместимому image по P06; источник/контент/grant, отозванные до rollback, не восстанавливаются. Наличие нового порядка не разрешает destructive schema down. Сохранять журналы оркестратора/этапов/агентов и все FAIL-раунды.
