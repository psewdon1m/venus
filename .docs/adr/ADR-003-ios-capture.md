# ADR-003 · iOS: capture и разрешённый app audio

**Дата:** 2026-10-18 · **ревизия:** P00-1 · **статус:** `DEFERRED`.

**Ответственный профиль:** iOS / RTC. **Принимающий:** Владелец mobile scope / QA. **Последний рубеж:** EXIT-P10.

## Контекст и вопрос

Проверить конкретный capture pipeline и распространение приложения на реальных устройствах.

## Варианты / подготовленное решение

Отдельный iOS publisher; исключить неподдерживаемые источники, desktop publishing остаётся альтернативой.

## Доказательства для принятия

Device/source matrix, A/V, revoke/termination/background tests; ограничения явно в UI.

## Последствия, совместимость и откат

Server capability restriction; учесть задержку store distribution и старые клиенты.
