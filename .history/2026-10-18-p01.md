Никакой production host или глобальный ingress не изменяется; только собственные disposable Compose projects и синтетические данные. Секреты не записываются. Образец `.history/example/` — отдельный локальный материал владельца, не часть публикуемого Venus.

## Реализация и первые проверки

- Зафиксированы Node24.22.0/npm11.19.1/Python3.12.14. Node проверен по официальным SHA256, установлен для работы в отдельный временный toolchain; глобальные пользовательские версии не заменены.
- TypeScript6.0.3 выбран в поддерживаемом typescript-eslint диапазоне; React/Vite, Fastify, pg и PostgreSQL16.14 закреплены exact versions/digests. npm и Python transitive dependencies имеют locks/hashes.
- Добавлены apps/web, apps/api и четыре packages; engine/catalog явно unavailable. Web — комфортный custom UI RU/EN/TR без фиктивных комнат.
- API выполняет SELECT1 для readiness, liveness отдельно, version согласован с build metadata. schema_generation0 честно обозначает отсутствие прикладных migrations.
- Логи ограничены разрешёнными полями; собственный request_id. Запросы/headers/query/body и raw DB errors не журналируются.
- Main защищён: PR, required quality/container-smoke, strict current base, enforce admins, no force/deletion. Обязательные checks привязаны к реальному GitHub Actions app15368. Обычный CI contents:read, pinned actions, без signing/release credentials.
- Первый Docker прогон выявил ошибку YAML tmpfs — запятая разбивала inline list; строка заключена в кавычки. Для публикации loopback app добавлена отдельная app-edge сеть; DB осталась только в internal backend. Повторный smoke прошёл.
- Negative harness использует временную копию, положительный контроль, ожидаемую диагностическую ошибку и проверку неизменности исходников. Исходная версия гейта проверяла связи недостаточно строго — это обнаружил отдельный reviewer ниже.

Foundation commit: `deaac55e693db7f27de2c7645e9bdb8aa1675ba5`. Создан [PR #1](https://github.com/psewdon1m/venus/pull/1). [Первый реальный PR CI](https://github.com/psewdon1m/venus/actions/runs/39143589394) PASS. Локально:70 Python +3 JS tests,4 negative fixtures,7 OCI checks PASS. Это ещё не означало принятия гейта.
